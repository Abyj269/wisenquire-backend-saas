# Release R1 (end of Phase 1)

Isolation hardening, D12 errors and reliability fixes. **Every new flag is OFF for existing clients**: the app behaves as before until a flag is turned on for an organization (see `docs/runbooks/flags-errors-tenant-status.md`, "Flag record").

## The "Agent" role template (D14)
- **What it is:** a role template at BRANCH level with data scope **OWN**. An agent with it sees and works only on their own records: the leads assigned to them; the chats where they are the agent or the lead is theirs; the customers, quotations and deliveries of those leads; and their own numbers on the dashboard. Company-wide reports are not available to them.
- **When it applies:** only when `own_scope.enforced` is ON for the organization. With the flag OFF (the default for every existing client), a role's OWN setting has no effect and agents keep seeing their whole branch, as today.
- **Existing roles keep data scope LEVEL.** Nothing changes for them. OWN is opt-in, per existing client.
- **New self-signup tenants** (Phase 2) get OWN enforced from the start, with the Agent template.
- **Unassigned work:** OWN agents do not see unassigned leads and chats unless `own_scope.include_unassigned` is also ON. With it ON, they may claim an unassigned lead or chat for themselves, but never assign one to someone else.
- **To switch a client to OWN:**
  1. Give the agents' role data scope OWN (Settings, Roles).
  2. Turn on `own_scope.enforced` for the org (and `own_scope.include_unassigned` if agents should pick up new enquiries).
  3. Check with one agent login.
  - **Rollback:** turn the flag off again.

## Other changes visible to users (flags OFF unless noted)
- Dates, "today", date filters and report day buckets follow each company's timezone (Indian and Gulf zones).
- The AI usage report uses company days; AI model rates are set by the platform and are read-only for tenants (D9).
- Users who may create a broadcast may now send it ("Save & Send Now" works for tenant roles).
- Clearer error messages (D12).
